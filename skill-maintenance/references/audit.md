# 审计细则（维护轮第 3 步）

## 1. 哈希盘点

```powershell
python <skill-maintenance>/scripts/check_skill.py --skill-dir <目标技能目录>
```

技能地图为每个文件记录 `sha256` + 行数/大小 + 最后核验轮次；盘点逐文件重算 `sha256` 比对（不只比大小）。有期望之外的差异时，逐条按来源分类。盘点只读，不修改文件。

- **引用扫描范围**：覆盖运行时文本文件（`SKILL.md` + `references/**/*.md` + `assets/**/*.md`），只做存在性与一致性检查，**不执行任何脚本**；`<...>` 占位符（如 `<提案ID>`）天然不匹配引用正则，无需特殊处理；引用路径一律以技能根目录为基准。裸文件名（如 `app.py`、`xxx.py`）视为文档示例，不做存在性校验；只有含目录分隔符的路径（如 `references/verdict-rules.md`）视为真实引用。
- **`--rebuild-map` 是写操作**（会重写账本“技能地图”），审计盘点不要带该 flag；只在收轮收尾、模板或脚本变更后使用。

## 2. 来源分类（不假装能定位到人/agent）

| 发现 | 判定 | 动作 |
|---|---|---|
| 哈希变化 + 账本/提案有记录 | 正常 | 无需动作 |
| 无记录 + `rounds/<上一轮>/snapshot/` 有旧版 | 越权候选 | 保留（补录账本）或回滚（从 snapshot 恢复） |
| 无记录 + 无快照 | 来源未知 | 不静默保留；开审计提案交 owner |
| 消失/新增 + 无记录 + 在同步白名单内 | 外部同步 | 不计越权；登记 owner 知悉 |
| 消失/新增 + 无记录 + 非白名单 | 来源未知 | 开审计提案交 owner |

## 3. 快照与回滚

- 每轮第 2 步把运行时表面复制到 `rounds/<轮次ID>/snapshot/`；回滚只从快照恢复。
- 无快照 → 只阻断，不回滚；交 owner。
- 回滚后在轮报告记录：恢复了哪些文件、从哪个快照。

## 4. 白名单

技能根目录下非本机制受治理的目录（外部分发的 skill-creator、create-skill 等）属于同步白名单；受治理技能不属于白名单。
